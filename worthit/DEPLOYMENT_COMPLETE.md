## 🎯 How to Use

### Access the App:
1. **Desktop**: Visit https://numaan7.github.io/worthit
2. **Mobile**: Open the URL in your mobile browser
3. **Install**: Look for the install prompt or use "Add to Home Screen"

### First-Time Setup:
1. Click "Sign in with Google"
2. Allow Google authentication
3. Add your Firebase configuration (if not already done)
4. Start tracking your net worth!

### Install as App:

**Desktop (Chrome/Edge):**
- Look for ⊕ icon in address bar
- Click "Install"
- App opens as standalone application

**Android:**
- Wait for install prompt banner (appears after 3 seconds)
- Tap "Install"
- Or use browser menu → "Add to Home Screen"

**iOS (Safari):**
- Tap Share button (box with arrow)
- Scroll and select "Add to Home Screen"
- Confirm installation

## ⚠️ Important Notes

### Firebase Configuration:
Before using the app, you need to configure Firebase:
1. Go to https://console.firebase.google.com/
2. Create/select your project
3. Enable Authentication (Google Sign-in)
4. Create Firestore Database
5. Update `/src/firebase.js` with your credentials
6. Add `numaan7.github.io` to Firebase authorized domains
7. Redeploy: `npm run deploy`

### PWA Limitations:
- **iOS**: Limited service worker features, manual install only
- **Offline**: Can view cached data but can't modify
- **First Visit**: Must be online first to cache resources
- **Updates**: Close all tabs and reopen for updates

## 🐛 Troubleshooting

### App Not Loading?
1. Clear browser cache
2. Try incognito/private mode
3. Check browser console for errors
4. Verify Firebase configuration
5. Test on different browser

### Install Prompt Not Showing?
1. Wait 3 seconds after page load
2. Check if already installed
3. Try different browser (Chrome recommended)
4. Verify HTTPS connection

### Offline Not Working?
1. Visit app online first (to cache resources)
2. Check service worker registration in DevTools
3. Verify cache storage has files
4. Toggle offline mode in DevTools Network tab
